# Favicon Directory

Place all your favicon assets and platform icons (e.g. `favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`, `site.webmanifest`) directly into this folder!

## Path Reference Guide:
With Vite, assets placed inside `/public/...` are served at the root of your application.

For example:
- A file saved as `public/favicon/favicon.ico` will be accessible at: `/favicon/favicon.ico`
- A file saved as `public/favicon/apple-touch-icon.png` will be accessible at: `/favicon/apple-touch-icon.png`

## Best-Practice `<head>` Tags:
You can use the following tags inside your `/index.html`:

```html
<link rel="apple-touch-icon" sizes="180x180" href="/favicon/apple-touch-icon.png">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon/favicon-16x16.png">
<link rel="manifest" href="/favicon/site.webmanifest">
```
